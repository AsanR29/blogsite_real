# blogsite
 The website has a very detailed umamusume recording section, in addition to the blogging.
 You could have an almost perfect record of your veterans prior to the introduction of the 2nd scenario.
 I haven't continued to add trainees for new banners, and I didn't complete the system to make it fully user-submitted information.
 I have no plans to continue updating this because I got bored of the game and stopped playing. To my knowledge, despite the incredible scene for fan-made tools related to umamusume none seem to do what my program does, except in the style of a spark-finder.
 If there isn't already one, I don't think one will ever be made either.

 The number 1 issue with this tool, for recording veteran details, is that data input is too slow. I tried adding methods to make it faster, but each one's impact was incremental. There are still more which could be added, but they too would be shaving seconds off of minutes. You can't get much faster than typing the first 3 letters of a Proper Noun, hitting Enter, Tab, and repeating.

 The basis of this program, the blog, was made in 1st year before I was knowledgable about app deployment. You probably can't host this website online without adding code, unless you're willing to upload your own version of the database file with an account set as an administrator.

 I learned an unusual amount about raw frontend dev from this.
